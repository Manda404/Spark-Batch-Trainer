Tutorials
=========

Cette section propose des tutoriels pratiques pour approfondir
l’utilisation de **Spark Batch Trainer**.

Exemples possibles :
- Comment créer des batchs stratifiés avec Spark.
- Comment appliquer un scheduler de learning rate.
- Comment tracer et interpréter une courbe d’apprentissage.
- Comment extraire les métriques d’entraînement.
