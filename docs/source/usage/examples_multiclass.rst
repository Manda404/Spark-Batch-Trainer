Multiclass classification
=========================

Multiclass training uses the same public workflow as binary training. Encode
the target as integer class identifiers before calling the trainer. This
example assumes three classes in a target column named ``label``.

XGBoost
-------

.. code-block:: python

   from spark_batch_trainer import create_trainer

   trainer = create_trainer("xgboost")
   trainer.fit(
       train_dataframe=train_df,
       valid_dataframe=validation_df,
       target_column="label",
       model_config={
           "objective": "multi:softprob",
           "num_class": 3,
           "eval_metric": "mlogloss",
           "n_estimators": 100,
           "learning_rate": 0.05,
           "random_state": 42,
       },
       training_config={"num_batches": 5, "max_patience": 3},
   )

Evaluation guidance
-------------------

Keep the test dataset separate from both training and validation. Use the
validation set for batch-level stopping and the test set once for final model
assessment. Report per-class metrics and a confusion matrix outside the
trainer; those artifacts are not generated by the library.

.. warning::

   Class identifiers, class count, and backend objective must agree. The
   library passes backend configuration through and cannot infer every invalid
   combination in advance.
